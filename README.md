# AI Creative Experiments

A collection of my experiments with AI-generated images, creative direction, and prompt iteration.

This repository isn't just about the final image. I want to document how an idea changes from one version to the next — including the versions that work, the versions that don't, and what I changed to improve them.

## What I'm Exploring

- AI image generation
- Prompt writing and refinement
- Creative direction
- Composition, lighting, and atmosphere
- Different visual styles
- Iterating on AI-generated results
- Turning an idea in my head into something visual

## How I Work

For each project, I start with an idea and generate an initial version.

From there, I look at what I like and what I don't like, adjust my direction or prompt, and create another version.

Sometimes the next version is better.

Sometimes it's worse.

Both are part of the process.

I keep different iterations so I can look back at how the project developed and what changes actually improved the result.

## Why GitHub?

I'm also using this repository to practice Git and GitHub while working on something creative.

Each project gives me a reason to practice:

- Branching for new versions and experiments
- Committing changes
- Pushing branches
- Comparing versions
- Merging the versions I want to keep

So this repository is both an AI creative portfolio and a record of my learning process.
